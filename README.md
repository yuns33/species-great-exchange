# 物种大漂流｜新航路上的物种交流

课堂互动 HTML 单文件小游戏，帮助学生掌握哥伦布大交换与新航路开辟后的主要跨洲物种交流。

## 玩法

1. 从左侧「物种档案库」拖拽卡片，放入底部对应原产大陆的投放框（美洲 / 欧亚 / 非洲）。
2. 正确归类会有成功音效与绿色反馈；错误会有提示音、红色闪光，卡片回到档案库。
3. 使用右上角画笔（多色）在世界地图上绘制物种交流航线，支持橡皮擦与撤销。
4. 完成全部 15 种物种后显示成绩与用时。

## 内置物种（高中历史相关）

- **美洲原产（6）**：玉米、马铃薯、甘薯、番茄、辣椒、南瓜
- **欧亚原产（8）**：小麦、大麦、水稻、苹果、葡萄、鸡、牛、羊
- **非洲原产（1）**：咖啡

## 使用方法

直接用浏览器打开 `物种大漂流.html` 即可，无需服务器。支持电脑鼠标与手机/平板触屏。

## 优化说明

- 地图区域占比提升，底部投放栏压缩，最大化地图显示
- 卡片轻微摇摆动画增强趣味
- 投放框专属红/绿闪光反馈
- 精简为课程核心 15 种物种，文件更干净
- 保留多色画笔、橡皮、计时、进度、线索提示、一键重开
