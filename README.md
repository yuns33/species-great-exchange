# 物种大漂流｜物种起源与传播互动学习项目

一个基于 **HTML、PHP、MySQL** 的互动式物种分类学习网站。玩家通过浏览动植物卡片，并将物种拖放到对应的原产大陆区域，了解物种起源、介绍和传播路径。

## 目录结构

```text
species_exchange_project/
├── index.html                 # 前台互动游戏页面
├── includes.php               # PHP 公共函数、数据库连接、登录与 CSRF 校验
├── config.sample.php          # 数据库配置示例（安装向导会生成 config.php）
├── api/
│   ├── species.php            # 前台物种数据接口
│   ├── settings.php           # 前台游戏设置接口
│   └── generate.php           # 传播路径文案生成接口
├── admin/
│   ├── login.php              # 管理员登录
│   ├── index.php              # 后台控制台
│   ├── species.php            # 物种增删改、图片和传播路径管理
│   ├── settings.php           # 游戏、AI 接口和管理员账号设置
│   └── logout.php             # 退出登录
├── install/
│   └── index.php              # 首次安装向导
├── assets/
│   ├── seed_species.json      # 25 条初始物种数据
│   └── ...                    # 初始物种图片资源
├── uploads/                   # 后台上传的图片
├── .htaccess                  # Apache 目录访问规则
└── README.md                  # 项目说明
```

## 功能说明

### 前台

- 展示动植物物种卡片及对应图片。
- 将物种拖放到 **美洲、欧亚、非洲** 对应区域，完成原产大陆分类。
- 触屏设备支持手指直接触碰并拖动卡片；桌面设备支持鼠标拖动。
- 提供物种介绍和传播路径信息。
- 提供正确、错误分类提示音。
- 支持挑战计时设置；倒计时设为 `0` 时使用正计时模式。
- 物种数据和游戏设置由 PHP API 从数据库读取。

### 管理后台

访问 `/admin/` 登录后台，可进行以下管理：

- 添加、编辑、删除物种。
- 设置物种名称、原产大陆、图标、介绍、传播路径、排序和前台显示状态。
- 上传物种图片，或填写图片 URL。
- 通过 Wikimedia Commons 检索可用图片。
- 配置挑战倒计时。
- 配置兼容 OpenAI Chat Completions 格式的 AI 接口地址、模型和 API Key，用于生成传播路径文案。
- 修改管理员账号和密码。

> 图片检索功能使用 Wikimedia Commons，不代表图片由 AI 生成。使用图片前请自行核对其授权和署名要求。AI 生成的传播路径内容也应核对史实。

## 环境要求

- PHP **8.0 或更高版本**（建议 PHP 8.1/8.2）。
- MySQL **5.7 或更高版本**，或 MariaDB **10.3 或更高版本**。
- PHP 扩展：`PDO`、`pdo_mysql`、`fileinfo`；使用 AI 接口时还需要 `curl`。
- Apache 或 Nginx 等支持 PHP 的 Web 服务器。
- 建议使用 HTTPS 部署。

## 安装步骤（宝塔面板）

1. 在宝塔面板添加网站，并将项目文件上传、解压到网站运行目录。
2. 为网站选择符合要求的 PHP 版本，并确认启用 `pdo_mysql`、`fileinfo`；需要 AI 功能时启用 `curl`。
3. 在宝塔数据库管理中创建 MySQL 数据库和数据库用户，并为该用户授予此数据库的使用权限。
4. 浏览器访问：

   ```text
   https://你的域名/install/
   ```

5. 填写数据库主机、数据库名、数据库用户名和密码。
6. 设置后台管理员账号和密码，然后提交安装。
7. 安装成功后，访问 `/admin/` 登录后台；访问 `/` 或 `/index.html` 打开前台。
8. **安装完成后立即删除或限制访问 `install/` 目录**，并在后台修改管理员账号密码。

安装向导会自动创建数据库表、写入 25 条初始物种数据，并在项目根目录生成 `config.php`。请勿将 `config.php` 或数据库密码公开。

## 默认后台账号

如果安装时没有修改初始值，默认账号为：

```text
账号：wsz
密码：wsz123456
```

这是首次安装的初始值。部署后请立即修改，不要在公网环境继续使用默认密码。

## AI 传播路径文案配置

1. 登录后台，打开“系统设置”。
2. 填写兼容 OpenAI Chat Completions 格式的接口地址。
3. 填写模型名称和 API Key。
4. 保存后，在物种管理页面填写物种名称等信息，点击“AI 生成传播路径说明”。

如果没有填写 API Key，系统会返回通用模板文案，并提示需要结合可靠资料核对具体传播时间和路线；这不等同于真实 AI 生成结果。API Key 保存在服务器端，不应写入前台 HTML。

## 触屏操作与声音说明

- 手机和平板：手指触碰物种卡片后即可拖动，拖到目标大陆区域并松开完成提交。
- 电脑：使用鼠标按住卡片拖动到目标区域。
- 正确和错误分类会尝试播放不同提示音。
- 浏览器和操作系统可能限制网页音频自动播放；设备静音模式、音量设置、省电策略或浏览器策略也可能影响声音。因此不能保证所有设备、所有浏览器设置下都一定发声。建议首次进入页面后进行一次主动触摸或点击，并确认设备没有静音。

## 安全与维护建议

- 使用 HTTPS，及时更新服务器 PHP 和数据库版本。
- 安装后删除或限制访问 `install/` 目录。
- 立即修改默认管理员账号密码，并使用强密码。
- 不要公开 `config.php`、数据库备份文件或 AI API Key。
- 定期备份 MySQL 数据库和 `uploads/` 目录。
- `uploads/` 目录用于图片文件；应保持禁止执行 PHP 等脚本的配置。
- 正式公网使用前，建议进一步增加登录失败限速、操作审计日志、强制 HTTPS 和自动备份策略。
